#Cemburu - Raim Laode (Animated Lyrics Display)

Proyek Python sederhana untuk menampilkan animasi lirik lagu "Cemburu" karya Raim Laode secara berurutan menggunakan teknik multithreading (threading) dan efek ketik berwaktu (time.sleep).

📌 Tentang Lagu

Lagu "Cemburu" menceritakan tentang perasaan dilema dan cemburu seseorang ketika melihat orang yang disukainya bersama orang lain. Perasaan ini diwarnai kepasrahan karena ia sadar tidak memiliki hak atau status untuk cemburu.

Aku cemburu melihat kau bersamanya

Aku cemburu tanganmu digenggam dia

Tapi ku tak tahu mengapa aku cemburu

Kau bukan milikku, kau bukan milikku

— Raim Laode

Lirik lengkap dan resmi dapat dicari secara langsung melalui pencarian di Google.

🚀 Fitur Utama

Multithreading: Menggunakan modul threading untuk mengontrol pewaktuan tayang setiap baris lirik.

Thread Safety: Menggunakan threading.Lock untuk memastikan output karakter di terminal/console konsisten dan tidak bentrok.

Efek Typewriter: Karakter ditampilkan satu per satu dengan jeda pengetikan yang halus.

💻 Cara Menjalankan

1. Prasyarat

Pastikan Python versi 3.x telah terinstal di komputer Anda.

2. Jalankan Script

Buka Command Prompt / Terminal, lalu masuk ke direktori proyek dan jalankan perintah berikut:

python cemburu_animated.py


Jika Anda menggunakan sistem Linux/macOS, gunakan perintah:

python3 cemburu_animated.py
